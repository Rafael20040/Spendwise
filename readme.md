# SpendWise 
SpendWise is a grocery expense analysis project developed with Python and Machine Learning.
The goal is to analyze supermarket purchases, organize products into categories, and eventually build a model capable of automatically classifying grocery products based on their descriptions.

## Features

- Grocery purchase dataset based on real supermarket receipts.
- Data cleaning and preprocessing with Pandas.
- Exploratory Data Analysis (EDA).
- Expense analysis by product category.
- Data visualization using Matplotlib and Seaborn.
- Planned: automatic product classification using Machine Learning.

## Current Status

The project is currently starting
The initial dataset contains 53 grocery purchase records from two supermarket receipts.
